# NetFleet Curriculum Sources and Authoring Policy

This is the approved source set for new and revised NetFleet lessons. A lesson must distinguish between a source used to explain a concept and an authoritative source used to verify a technical claim.

## Source-use order

1. **Standards and official product documentation** establish protocol behavior, APIs, command behavior and security limits.
2. **The approved books and courses below** shape sequencing, explanations, diagrams, examples and practice.
3. **Original NetFleet material** turns the sources into Persian, project-based learning. It must not copy substantial text or present simplified lab behavior as a production guarantee.

Every technical lesson should name its most relevant sources. A lab must state its scope, safe environment and rollback/verification method when it can change a system.
