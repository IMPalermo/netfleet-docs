Day 01 | Python Fundamentals

The Foundation of Infrastructure Automation

جلسه اول مسیر مهندسی پایتون در پروژه NetFleet

جلسه اول: مبانی پایتون

NETFLEET LEARNING PATH / PYTHON ENGINEERING / WEEK 01

۱. مقدمه: چرا پایتون؟

تصور کن یک زیرساخت شبکه شامل ۱۰۰ سرور لینوکسی، چندین روتر و تعداد زیادی سرویس مختلف داری.

برای مدیریت این زیرساخت باید بتوانی کارهایی مثل موارد زیر را انجام بدهی:

  • وضعیت سرورها را بررسی کنی.
  • اطلاعات تجهیزات شبکه را جمع‌آوری کنی.
  • سرویس‌های مختلف را کنترل کنی.
  • فایل‌های پیکربندی را تولید و ویرایش کنی.
  • عملیات تکراری را به‌صورت خودکار انجام بدهی.

انجام دستی این عملیات زمان‌بر است و احتمال خطای انسانی را افزایش می‌دهد.

اینجاست که برنامه‌نویسی وارد مهندسی زیرساخت می‌شود.

زبان Python به دلیل سادگی، کتابخانه‌های گسترده و قابلیت ارتباط با سیستم‌عامل، شبکه و سرویس‌های مختلف، یکی از ابزارهای مهم در حوزه اتوماسیون زیرساخت است.

در پروژه NetFleet قرار است از پایتون برای ساخت ابزارهایی استفاده کنیم که در آینده بتوانند اطلاعات زیرساخت را دریافت، پردازش و مدیریت کنند.

هدف این جلسه

در پایان این جلسه باید بتوانی:

  1. مفهوم متغیر را درک کنی.
  2. انواع داده‌های اصلی پایتون را تشخیص بدهی.
  3. اطلاعات را در لیست و دیکشنری ذخیره کنی.
  4. ساختار لیستی از دیکشنری‌ها را بسازی.
  5. با حلقه‌های تکرار کار کنی.
  6. داده‌های ساده مربوط به زیرساخت را پردازش کنی.

۲. مفهوم متغیر (Variable)

یکی از اولین مفاهیمی که در برنامه‌نویسی باید یاد بگیری، متغیر است.

متغیر را می‌توان یک نام برای دسترسی به یک مقدار در حافظه در نظر گرفت.

برای مثال، فرض کن می‌خواهیم نام یک سرور را در برنامه نگهداری کنیم.

hostname = "server-01"

در این مثال:

  • hostname نام متغیر است.
  • = عملگر انتساب است.
  • "server-01" مقداری است که به متغیر اختصاص داده‌ایم.

انتساب چگونه کار می‌کند؟

وقتی دستور زیر اجرا می‌شود:

hostname = "server-01"

پایتون مقدار "server-01" را به نام hostname اختصاص می‌دهد.

بعداً می‌توانیم با استفاده از نام متغیر به مقدار آن دسترسی پیدا کنیم.

hostname = "server-01"

print(hostname)

خروجی:

server-01

تابع print() برای نمایش اطلاعات در خروجی استفاده می‌شود.

تغییر مقدار متغیر

متغیرها می‌توانند در طول اجرای برنامه مقدار جدیدی دریافت کنند.

hostname = "server-01"

hostname = "server-02"

print(hostname)

خروجی:

server-02

در این مثال مقدار قبلی دیگر از طریق نام hostname قابل دسترسی نیست و مقدار جدید جایگزین آن شده است.

نکته مهندسی

در پروژه‌های زیرساختی بهتر است نام متغیرها معنی‌دار باشد.

مثلاً:

server_ip = "192.0.2.10"
server_port = 22
server_name = "netfleet-node-01"

این نام‌گذاری باعث می‌شود وقتی چند ماه بعد کد را بررسی می‌کنی، سریع‌تر متوجه کاربرد هر متغیر شوی.

۳. انواع داده (Data Types)

هر مقداری که در پایتون نگهداری می‌کنیم، یک نوع داده دارد.

نوع داده مشخص می‌کند که اطلاعات چه ماهیتی دارند و چه عملیات‌هایی می‌توان روی آن‌ها انجام داد.

چهار نوع داده مهم در این مرحله عبارت‌اند از:

۳.۱. رشته (String)

برای نگهداری متن استفاده می‌شود.

hostname = "server-01"
operating_system = "Ubuntu"
username = "admin"

رشته‌ها معمولاً داخل کوتیشن قرار می‌گیرند.

۳.۲. عدد صحیح (Integer)

برای نگهداری اعداد صحیح استفاده می‌شود.

port = 22
cpu_cores = 8
ram_gb = 32

۳.۳. عدد اعشاری (Float)

برای نگهداری اعداد دارای بخش اعشاری استفاده می‌شود.

cpu_usage = 37.5
temperature = 48.6

۳.۴. مقدار منطقی (Boolean)

برای نمایش دو وضعیت منطقی استفاده می‌شود:

  • True
  • False

مثال:

server_online = True
firewall_enabled = False

این مقادیر در برنامه‌های مدیریتی برای نمایش وضعیت سرویس‌ها و تجهیزات کاربرد زیادی دارند.

بررسی نوع داده

با تابع type() می‌توانیم نوع یک مقدار را بررسی کنیم.

hostname = "server-01"
port = 22
cpu_usage = 37.5
server_online = True

print(type(hostname))
print(type(port))
print(type(cpu_usage))
print(type(server_online))

خروجی:

<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>

جمع‌بندی انواع داده

نوع داده مثال کاربرد
String "Ubuntu" نام سیستم‌عامل
Integer 22 شماره پورت
Float 37.5 میزان مصرف CPU
Boolean True وضعیت آنلاین بودن

۴. ساختار لیست (List)

گاهی لازم است چند مقدار مرتبط را در یک متغیر نگهداری کنیم.

برای مثال، یک زیرساخت ممکن است چندین سرور داشته باشد.

به‌جای تعریف متغیر جداگانه برای هر سرور، می‌توانیم از لیست استفاده کنیم.

servers = [
    "server-01",
    "server-02",
    "server-03"
]

لیست مجموعه‌ای مرتب از مقادیر است.

دسترسی به اعضای لیست

هر عضو لیست یک شماره موقعیت یا Index دارد.

نکته مهم این است که شماره‌گذاری در پایتون از صفر شروع می‌شود.

servers = [
    "server-01",
    "server-02",
    "server-03"
]

print(servers[0])
print(servers[1])
print(servers[2])

خروجی:

server-01
server-02
server-03

افزودن عضو جدید

با متد append() می‌توانیم یک عضو به انتهای لیست اضافه کنیم.

servers = [
    "server-01",
    "server-02"
]

servers.append("server-03")

print(servers)

خروجی:

['server-01', 'server-02', 'server-03']

تعداد اعضای لیست

با تابع len() تعداد اعضای یک لیست را به دست می‌آوریم.

servers = [
    "server-01",
    "server-02",
    "server-03"
]

print(len(servers))

خروجی:

3

کاربرد در NetFleet

در آینده ممکن است سامانه NetFleet فهرستی از صدها سرور را از یک منبع اطلاعاتی دریافت کند.

لیست می‌تواند یکی از ساختارهای اولیه برای نگهداری این اطلاعات باشد.

۵. ساختار دیکشنری (Dictionary)

لیست برای نگهداری مجموعه‌ای از مقادیر مناسب است؛ اما وقتی هر مقدار ویژگی مشخصی داشته باشد، دیکشنری انتخاب بهتری خواهد بود.

فرض کن اطلاعات یک سرور را داریم:

  • نام سرور
  • آدرس IP
  • سیستم‌عامل
  • شماره پورت SSH

می‌توانیم این اطلاعات را در یک دیکشنری ذخیره کنیم.

server = {
    "hostname": "server-01",
    "ip_address": "192.0.2.10",
    "operating_system": "Ubuntu",
    "ssh_port": 22
}

دیکشنری اطلاعات را به شکل جفت‌های کلید و مقدار نگهداری می‌کند.

هر جفت از دو بخش تشکیل شده است:

  • Key: نام ویژگی
  • Value: مقدار ویژگی

برای مثال:

"hostname": "server-01"

در این ساختار:

  • hostname کلید است.
  • server-01 مقدار است.

دسترسی به اطلاعات دیکشنری

برای دریافت مقدار هر ویژگی، از کلید آن استفاده می‌کنیم.

print(server["hostname"])
print(server["ip_address"])
print(server["operating_system"])
print(server["ssh_port"])

خروجی:

server-01
192.0.2.10
Ubuntu
22

تغییر مقدار

می‌توانیم مقدار یک ویژگی را تغییر بدهیم.

server["ssh_port"] = 2222

print(server["ssh_port"])

خروجی:

2222

افزودن ویژگی جدید

server["status"] = "online"

print(server)

اکنون دیکشنری یک ویژگی جدید به نام status دارد.

چرا دیکشنری مهم است؟

در سیستم‌های زیرساختی، اطلاعات معمولاً ساختارمند هستند.

مثلاً هر سرور دارای IP، سیستم‌عامل، پورت، وضعیت و مشخصات سخت‌افزاری است.

دیکشنری به ما اجازه می‌دهد این اطلاعات را با نام‌های مشخص و قابل فهم ذخیره کنیم.

۶. لیست دیکشنری‌ها (List of Dictionaries)

اینجا به یکی از ساختارهای بسیار مهم برای توسعه NetFleet می‌رسیم.

فرض کن فقط یک سرور نداریم و می‌خواهیم اطلاعات چند سرور را نگهداری کنیم.

برای این کار می‌توانیم دیکشنری‌های مختلف را داخل یک لیست قرار بدهیم.

servers = [
    {
        "hostname": "server-01",
        "ip_address": "192.0.2.10",
        "os": "Ubuntu",
        "status": "online"
    },
    {
        "hostname": "server-02",
        "ip_address": "192.0.2.11",
        "os": "Debian",
        "status": "offline"
    },
    {
        "hostname": "server-03",
        "ip_address": "192.0.2.12",
        "os": "Ubuntu",
        "status": "online"
    }
]

در این مثال:

  • متغیر servers یک لیست است.
  • هر عضو لیست یک دیکشنری است.
  • هر دیکشنری اطلاعات یک سرور را نگهداری می‌کند.

دسترسی به اطلاعات

برای دریافت نام اولین سرور:

print(servers[0]["hostname"])

خروجی:

server-01

برای دریافت IP دومین سرور:

print(servers[1]["ip_address"])

خروجی:

192.0.2.11

ترکیب دو ساختار را می‌توان این‌طور درک کرد:

servers[1]["hostname"]

ابتدا عضو دوم لیست را انتخاب می‌کنیم و سپس مقدار کلید hostname را از دیکشنری آن دریافت می‌کنیم.

این الگو در پردازش اطلاعات APIها و سامانه‌های مدیریت زیرساخت بسیار پرکاربرد است.

۷. حلقه تکرار (For Loop)

تصور کن ۱۰۰ سرور در لیست داریم.

آیا باید برای نمایش اطلاعات هر سرور یک دستور print() جداگانه بنویسیم؟

خیر.

با حلقه for می‌توانیم یک عملیات را برای اعضای مختلف یک مجموعه تکرار کنیم.

مثال:

servers = [
    "server-01",
    "server-02",
    "server-03"
]

for server in servers:
    print(server)

خروجی:

server-01
server-02
server-03

حلقه چگونه اجرا می‌شود؟

به این بخش توجه کن:

for server in servers:
    print(server)

اجرای حلقه به این شکل است:

  1. پایتون اولین عضو لیست را دریافت می‌کند.
  2. مقدار آن را در متغیر server قرار می‌دهد.
  3. دستورهای داخل حلقه را اجرا می‌کند.
  4. عضو بعدی را دریافت می‌کند.
  5. این فرآیند تا پایان لیست ادامه پیدا می‌کند.

حلقه روی لیست دیکشنری‌ها

حالا مثال قبلی NetFleet را توسعه می‌دهیم.

servers = [
    {
        "hostname": "server-01",
        "ip_address": "192.0.2.10"
    },
    {
        "hostname": "server-02",
        "ip_address": "192.0.2.11"
    },
    {
        "hostname": "server-03",
        "ip_address": "192.0.2.12"
    }
]

for server in servers:
    print(server["hostname"])
    print(server["ip_address"])
    print("----------------")

خروجی:

server-01
192.0.2.10
----------------
server-02
192.0.2.11
----------------
server-03
192.0.2.12
----------------

در اینجا هر بار متغیر server یکی از دیکشنری‌های موجود در لیست را دریافت می‌کند.

به همین دلیل می‌توانیم به کلیدهای آن دسترسی داشته باشیم.

کاربرد واقعی در NetFleet

در آینده می‌توانیم از همین الگو برای کارهایی مثل این استفاده کنیم:

  • بررسی فهرست سرورها
  • جمع‌آوری آدرس IP تجهیزات
  • تولید گزارش زیرساخت
  • بررسی وضعیت سرویس‌ها
  • ارسال درخواست به چندین دستگاه شبکه

۸. تفاوت علامت انتساب و مقایسه

دو علامت مهم وجود دارند که نباید با یکدیگر اشتباه گرفته شوند.

علامت =

برای اختصاص دادن مقدار به یک متغیر استفاده می‌شود.

port = 22

یعنی مقدار ۲۲ را به متغیر port اختصاص بده.

علامت ==

برای مقایسه دو مقدار استفاده می‌شود.

port = 22

print(port == 22)

خروجی:

True

یعنی آیا مقدار port برابر با ۲۲ است؟

در جلسات بعدی، از این مفهوم برای ساخت شرط‌ها و تصمیم‌گیری در برنامه استفاده خواهیم کرد.

۱۰. تمرین‌های عملی

این قسمت برای اطمینان از یادگیری مفاهیم طراحی شده است.

تمرین اول: اطلاعات یک سرور

یک دیکشنری به نام server بساز و اطلاعات زیر را در آن قرار بده:

  • نام سرور: netfleet-node-01
  • آدرس IP: 192.0.2.20
  • سیستم‌عامل: Ubuntu
  • پورت SSH: 22
  • وضعیت: online

سپس نام سرور و آدرس IP آن را با print() نمایش بده.

تمرین دوم: مدیریت چند سرور

یک لیست شامل سه دیکشنری بساز.

هر دیکشنری باید اطلاعات یک سرور را نگهداری کند.

سپس با حلقه for نام تمام سرورها را نمایش بده.

تمرین سوم: شمارش سرورها

با استفاده از تابع len() تعداد سرورهای موجود در لیست را نمایش بده.

تمرین چهارم: توسعه اطلاعات

به یکی از دیکشنری‌های موجود در لیست، ویژگی جدیدی به نام location اضافه کن.

مقدار آن را برابر با Germany قرار بده.

سپس مقدار جدید را نمایش بده.

تمرین پنجم: تحلیل کد

خروجی کد زیر چیست؟

servers = [
    {"hostname": "node-01", "port": 22},
    {"hostname": "node-02", "port": 2222},
    {"hostname": "node-03", "port": 22}
]

for server in servers:
    print(server["hostname"])
    print(server["port"])

بدون اجرای کد، ابتدا خروجی را پیش‌بینی کن و بعد آن را اجرا کن.

۱۲. ارتباط این جلسه با معماری NetFleet

هدف ما صرفاً یادگیری دستورات پایتون نیست.

می‌خواهیم این مفاهیم را در ساخت یک سیستم واقعی استفاده کنیم.

در معماری آینده NetFleet:

لایه کاربرد
Data Collection دریافت اطلاعات سرورها
Data Processing پردازش اطلاعات دریافتی
Data Storage ذخیره اطلاعات ساختارمند
Automation Engine اجرای عملیات خودکار
Monitoring بررسی وضعیت زیرساخت

مفاهیمی که امروز یاد گرفتیم، پایه بخش پردازش اطلاعات و ساختار داده در این معماری هستند.

برای مثال، یک پاسخ API ممکن است شامل اطلاعات چندین سرور باشد. ما باید بتوانیم آن اطلاعات را دریافت کنیم، ساختارشان را بشناسیم و روی آن‌ها عملیات انجام بدهیم.

این دقیقاً همان چیزی است که در جلسات آینده توسعه خواهیم داد.
