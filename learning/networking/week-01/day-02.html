Week 01 | Day 02

مدل‌های OSI و TCP/IP

اهداف یادگیری

در پایان این جلسه باید بتوانی: - لایه‌های هفت‌گانه OSI را توضیح بدهی. - مدل TCP/IP را با OSI مقایسه کنی. - مفهوم Encapsulation و Decapsulation را درک کنی. - برای مشکلات شبکه، لایه احتمالی خطا را تشخیص بدهی.

1. چرا به مدل شبکه نیاز داریم؟

شبکه از اجزای متعددی تشکیل شده است: کارت شبکه، سوئیچ، روتر، سیستم‌عامل، پروتکل‌ها و برنامه‌ها.

اگر تمام این اجزا بدون ساختار مشترک طراحی می‌شدند، ارتباط بین تجهیزات مختلف بسیار دشوار بود.

مدل‌های شبکه، ارتباط را به بخش‌های کوچک‌تر تقسیم می‌کنند. هر لایه مسئولیت مشخصی دارد و با لایه‌های مجاور تعامل می‌کند.

2. مدل OSI

مدل OSI یک مدل مرجع هفت‌لایه‌ای است.

شماره لایه وظیفه اصلی
7 Application سرویس‌های شبکه برای برنامه‌ها
6 Presentation قالب‌بندی، رمزنگاری و فشرده‌سازی
5 Session مدیریت نشست ارتباطی
4 Transport ارتباط انتها به انتها و پورت‌ها
3 Network آدرس‌دهی منطقی و مسیریابی
2 Data Link فریم، MAC و ارتباط محلی
1 Physical انتقال بیت روی رسانه

لایه‌های مهم در عمل

Layer 1: Physical

کابل، فیبر نوری، سیگنال رادیویی، کانکتور و سرعت انتقال در این لایه قرار می‌گیرند.

Layer 2: Data Link

ارتباط در شبکه محلی، Ethernet، MAC Address و Switching در این لایه مطرح هستند.

Layer 3: Network

IP Address و Routing وظایف اصلی این لایه‌اند.

Layer 4: Transport

TCP و UDP و شماره پورت‌ها در این لایه قرار می‌گیرند.

Layer 7: Application

پروتکل‌هایی مانند HTTP، DNS و SSH در این سطح استفاده می‌شوند.

نکته: مدل OSI یک مدل مفهومی است. نباید تصور کنیم تمام پروتکل‌های واقعی دقیقاً در یک خانه از آن قرار می‌گیرند.

3. مدل TCP/IP

مدل TCP/IP به معماری واقعی اینترنت نزدیک‌تر است.

TCP/IP لایه‌های متناظر OSI
Application 5، 6، 7
Transport 4
Internet 3
Network Access 1، 2

در بسیاری از منابع، لایه آخر TCP/IP با نام Link نیز معرفی می‌شود.

4. Encapsulation چیست؟

هنگامی که یک برنامه داده‌ای ارسال می‌کند، هر لایه اطلاعات کنترلی مورد نیاز خود را به آن اضافه می‌کند.

فرآیند ساده‌شده:

  1. Application: داده برنامه
  2. Transport: اضافه شدن TCP یا UDP Header
  3. Network: اضافه شدن IP Header
  4. Data Link: اضافه شدن Ethernet Header و Trailer
  5. Physical: تبدیل به سیگنال و ارسال

در سمت گیرنده، فرآیند معکوس انجام می‌شود که Decapsulation نام دارد.

اصطلاحات مهم

لایه واحد داده
Application Data
Transport Segment یا Datagram
Network Packet
Data Link Frame
Physical Bits

5. مثال واقعی

فرض کن در مرورگر آدرس یک وب‌سایت را وارد می‌کنی.

  • مرورگر درخواست HTTP را ایجاد می‌کند.
  • لایه Transport داده را در TCP قرار می‌دهد.
  • لایه Network آدرس IP مبدأ و مقصد را اضافه می‌کند.
  • لایه Data Link فریم Ethernet را آماده می‌کند.
  • کارت شبکه داده را ارسال می‌کند.

هر لایه وظیفه خودش را انجام می‌دهد؛ این جداسازی باعث می‌شود سیستم پیچیده شبکه قابل مدیریت باشد.

PowerShell را باز کن.

مشاهده تنظیمات IP

بررسی مسیر ارتباط

tracert 8.8.8.8

هر دستور از زاویه متفاوتی به شبکه نگاه می‌کند. خروجی‌ها را ذخیره کن و تفاوتشان را توضیح بده.

7. تمرین عیب‌یابی

برای هر مشکل، لایه محتمل را مشخص کن:

  1. کابل Ethernet قطع شده است.
  2. سیستم IP معتبر ندارد.
  3. Gateway قابل دسترسی نیست.
  4. پورت TCP سرویس بسته است.
  5. وب‌سایت درخواست HTTP را رد می‌کند.

ممکن است یک مشکل چند لایه را درگیر کند؛ هدف، انتخاب نقطه شروع منطقی برای عیب‌یابی است.

8. ارتباط با Network Automation

یک مهندس Network Automation باید بتواند داده‌های شبکه را در لایه‌های مختلف جمع‌آوری و تحلیل کند.

برای مثال: - بررسی وضعیت Interfaceها - خواندن IP Configuration - بررسی Routeها - تست TCP Portها - تحلیل درخواست‌های API

شناخت لایه‌ها کمک می‌کند خروجی ابزارهای اتوماسیون را درست تفسیر کنی.
