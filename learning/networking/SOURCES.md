# Networking Curriculum — Primary Sources

NetFleet lessons use primary standards and vendor documentation as the technical authority. Explanations and examples are original Persian teaching material; learners should use the sources below to verify protocol behavior and continue their study.

## Source-use rule

When an RFC, IEEE standard or product documentation differs from a simplified example in a lesson, the primary source is authoritative. Simplified examples explicitly state their limits and must not be copied into production configurations without validating the relevant platform documentation.
